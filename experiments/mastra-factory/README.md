# experiments/mastra-factory

Prueba rápida de Mastra Factory (beta, Apache-2.0) para decidir si sirve como tablero y orquestador
de la fábrica (nivel 4). Ítem: FACTORY-10. Notas y conclusiones: `vault/06-lecciones/` al terminar.

Reglas de la prueba:
- Solo el repo de juguete `alephart/factory-sandbox`. La GitHub App de Mastra **no** recibe acceso a ningún repo real.
- Auto-start y auto-approve apagados: cada etapa espera aprobación.
- Llave de modelo de prueba, con límite de gasto.
